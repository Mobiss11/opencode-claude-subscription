# Диагноз: 400 «Third-party apps now draw from your extra usage»

Дата живых проб: **05.10.2026**. Проведены напрямую против kraube serve
(= против Anthropic через OAuth-подписку), модель `claude-opus-5-5`,
max_tokens 16, одинаковый user-запрос «Say OK».

## Симптом

Запросы OpenCode через шлюз падают с 400, обычные curl-запросы с
system-промптом проходят:

```json
{"type":"error","error":{"type":"invalid_request_error",
 "message":"Third-party apps now draw from your extra usage, not your plan
  limits. Add more at claude.ai/settings/usage and keep going."}}
```

Anthropic классифицирует запрос как «third-party app»: тарификация через
extra-usage кредиты вместо лимитов плана; без кредитов — детерминированный
400 (не флейк, ретраи не лечат).

## Дифференциальные пробы

| # | system-промпт | Ответ | Вывод |
| --- | --- | --- | --- |
| 1 | `"You are a helpful assistant."` | 200 | база проходит |
| 2 | `"You are an AI agent running in OpenCode, a coding agent harness. …"` | 200 | **агентная идентичность не триггерит** |
| 3 | `<env>` с посторонним текстом | 200 | теги сами по себе не триггерят |
| 4 | `"Working directory: /Users/…"` одной строкой | 200 | одиночное поле не триггерит |
| 5 | поля окружения (4 шт.) без тегов, без даты/интро | 200 | поля без обрамления не триггерят |
| 6 | `Today's date: …` + интро + `<env>…</env>` с полями | **400** | **секция целиком = триггер** |
| 7 | то же, но system как массив блоков | **400** | форма (строка/блоки) не важна |
| 8 | секция целиком в первом **user**-сообщении | 200 | **в user-сообщении не триггерит** |

Итог: триггер — связка `Today's date:` + строка-интро «Here is some
useful information about the environment you are running in:» + поля
окружения (обычно в `<env>…</env>`), то есть **env-секция OpenCode в
system-промпте**. Идентичность агента («You are … OpenCode …»), теги и
поля по отдельности проходят.

## Фикс

`anthropic_bridge.move_env_to_user` (флаг upstream'а шлюза
`move_env_to_user: true`, для kraube включён):

- env-секция вырезается из system **целиком и дословно** (дата + интро +
  блок с тегами, исходное форматирование);
- вставляется текст-блоком в начало первого user-сообщения (после ведущих
  `tool_result`-блоков);
- незакрытый `<env>` не трогается; без флага system уходит как есть;
- модель контекст не теряет (секция остаётся в диалоге), классификация
  не срабатывает (проба 8).

Регрессионный тест живёт в `tests/test_anthropic_bridge.py`
(`test_move_env_to_user_*`), а сценарий №6 (историческое падение)
воспроизводится внешне скриптом `verify.sh` этого репозитория.

## Оговорка

Поведение классификации зафиксировано на дату проб и может измениться
политикой Anthropic. Если 400 с «extra usage» вернётся при включённом
`move_env_to_user` — повторите дифференциальные пробы (curl напрямую в
kraube serve, шаблоны — в таблице выше) и обновите эту страницу.
